# Lisenser for filene i denne mappen

| Fil | Kilde | Lisens |
|---|---|---|
| `Inter-Regular.otf`, `Inter-Medium.otf`, `Inter-SemiBold.otf` | Inter, Rasmus Andersson (rsms.me/inter) | SIL Open Font License 1.1 |
| `MaterialIcons-Regular.ttf` | Google, github.com/google/material-design-icons | Apache License 2.0 |
| `ikoner.txt` | Kodepunktene for ikonene som brukes, fra samme repo | Apache License 2.0 |

Skriftene brukes bare av `src/powerbi/lag_bilder.py` til å tegne bakgrunnsbildene.
Selve rapporten bruker Segoe UI, som følger med Windows.
